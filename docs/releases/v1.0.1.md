# SOLSTICE v1.0.1 — HDR 后期兼容性修复

| 字段 | 值 |
| --- | --- |
| 版本 | `1.0.1` |
| Git tag | `v1.0.1` |
| 日期 | 2026-10-18 |
| 状态 | 当前稳定版本 |
| 关联事故 | [INC-2026-001](../incidents/INC-2026-001-half-float-post-processing-corruption.md) |

## 修复内容

- 后期 RenderTarget 默认使用 `THREE.UnsignedByteType`（LDR），不再根据扩展存在与否自动启用 HalfFloat/HDR。
- 修复受影响 GPU/ANGLE 环境中的全屏彩色雪花、柔焦和偶发正常帧。
- HDR 路径保留，但仅在显式传入 `{ hdr: true }` 且扩展可用时启用；默认游戏不启用。
- 修复 `setQuality()` 在低画质下把 LDR 阈值覆盖为 HDR 阈值的问题。
- 新增 `renderMode`、`hdrAvailable` 诊断属性。

## 阈值调整

| 格式 | high | low |
| --- | --- | --- |
| LDR | `.68` | `.82` |
| HDR | `1.02` | `1.20` |

LDR 关闭了 HDR 的 >1.0 高光余量，因此使用独立的亮部阈值。当前视觉验证表明默认画面稳定；若需要更强的 bloom 高光层次，应另立画质调优任务，而不是重新自动启用 HDR。

## 兼容性说明

- 这是**兼容优先**的修复：默认牺牲少量 HDR 高光余量，换取跨未知 GPU 的稳定性。
- HDR 当前不是玩家可选项；只保留给受控诊断或已验证设备。
- 不需要迁移存档或配置；刷新页面即可使用新版本。

## 验证

- 现场 A/B：HDR 路径间歇性故障；LDR 路径持续正常。
- 全部 JavaScript 文件通过语法检查。
- 默认/显式 HDR/无扩展/低画质四种构造配置通过阈值检查。
- 详见 [VER-2026-001](../verification/VER-2026-001-ldr-fallback.md)。

## 已知限制

- 未对全部 GPU/浏览器组合做回归；
- 未做长时间 soak test；
- HDR opt-in 在其他设备上的稳定性仍未建立矩阵；
- LDR 的曝光和 bloom 权重仍可继续做美术调优。
