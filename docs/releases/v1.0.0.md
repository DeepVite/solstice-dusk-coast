## 内容

首个公开版本，包含：

- three.js r149 低模体素海岸与程序化洞穴；
- 永恒日落、云层、海面反射、日光路、薄雾与长影；
- 结构支撑与坍塌、树木倒伏、巨砾滚动、碎石与粉尘；
- 第一人称移动、破坏/放置、创造飞行、物品栏；
- 程序化 WebAudio 与完整 HUD/菜单；
- MIT 许可与 three.js 第三方许可。

## 已知问题

本版本在 WebGL2 且浮点颜色缓冲扩展可用时，会自动使用 HalfFloat/HDR 后期 RenderTarget。

在部分 GPU / ANGLE / Direct3D 驱动组合上，这会令整个 3D 画面出现：

- 全屏彩色雪花；
- 高斯模糊一样的柔焦；
- 偶发正常帧；
- 暂停/继续或改变窗口尺寸后短暂恢复。

DOM UI 不受影响。完整分析见 [INC-2026-001](../incidents/INC-2026-001-half-float-post-processing-corruption.md)。

## 说明

该缺陷在本版本中**有意保留**，用于复现和审计。修复位于 `v1.0.1`：

- [v1.0.1 发布说明](v1.0.1.md)

## 升级建议

受影响设备请使用 `v1.0.1` 或更新版本。无存档迁移需求（项目当前没有持久化存档）。
